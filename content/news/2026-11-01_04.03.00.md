# 4.3 (2026-11-01)

## Improved support for passthrough options

The previous release of releng-tool added support from the command line to
accept a build identifier value. This was done through the
[`--build-id`](arg-build-id) argument which in turn populated an
environment/script variable [`RELENG_BUILD_ID`](env-releng-build-id). This
release now extends this capability with two changes. First, the
[`RELENG_BUILD_ID`](env-releng-build-id-set) environment variable can be set
before running releng-tool to make it easier for builders who opt for use of
environment variables over populating a command line argument.

While a build identifier can be explicitly provided from either a command line
argument or environment variable, releng-tool now also supports implicitly
populating a build identifier through various common vendor tools. The
following vendor tools are checked based on their pipeline/job documentation
for an identifier value:

- AWS CodeBuild
- Azure Pipelines
- Bitbucket Pipelines
- CircleCI
- Forgejo
- GitHub
- GitLab
- Jenkins
- Travis CI
- Woodpecker

Developers can opt-out of an implicit build identifier by setting the
[`RELENG_BUILD_ID_NO_IMPLICIT`](env-releng-build-id-no-implicit) environment
variable.

Additionally, this release includes a new [`--build-variant`](arg-build-variant)
argument and [`RELENG_BUILD_VARIANT`](env-releng-build-variant) variable. The
goal is to help identify special builds such as a debug-enabled variant build.
For example, a provided string can be passed to a post-build phase which can be
used when building the name of a package.

For more information, see
[passthrough options](/guides/tips/passthrough-options).

## SPDX license database updated

The internally managed copy of the [SPDX license identifiers][spdx] has
been updated to the most recent version (v3.29).

## Planned Removals Next Release

The following features are planned to be removed next release:

- Support for Python 3.10 (EOL) will be dropped.
- Support for the `LIBFOO_REMOTE_CONFIG` option
- Support for the `LIBFOO_REMOTE_SCRIPTS` option
